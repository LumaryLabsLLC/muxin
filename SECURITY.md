# Security

Muxen runs commands on your machines and holds your connections to them, so we
take security problems seriously.

## Reporting a problem

Please report it privately, not in a public issue:

- on GitHub, with **Security › Report a vulnerability** on this repository, or
- by email to contact@lumarylabs.com.

Say what the problem is, how to reproduce it, and what someone could do with
it. We'll reply within a few days, keep you posted while we fix it, and credit
you when it's released if you'd like.

## What's covered

The app, its command line and MCP server (`muxen`), and the agent it installs
on machines (`muxen-agent`), in the latest release.
